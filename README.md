# Каруселі @tsebakk

- `ІНСТРУКЦІЯ.md` — майстер-промпт: бренд, візуальний код, структура каруселі, як працювати.
- `carousel_kit.py` — програма, що збирає слайди 1080×1350 (стиль v2): `python carousel_kit.py spec.json out`
- `fonts/` — Montserrat і Great Vibes (використовуються), Playfair і Marck Script (запас).
- `приклад/spec.json` — еталонна карусель «5 фраз з дитинства, які забрали твій голос» у стилі v2. Фото до неї в репозиторій не кладемо.
- `каруселі/` — сюди складаємо нові каруселі: `каруселі/<дата-тема>/spec.json`, `фото/`, `out/`.

Для Claude: на початку сесії прочитай `ІНСТРУКЦІЯ.md` і дотримуйся її.
