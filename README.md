# Каруселі @tsebakk

- `ІНСТРУКЦІЯ.md` — майстер-промпт: бренд, візуальний код, структура каруселі, як працювати.
- `carousel_kit.py` — програма, що збирає слайди 1080×1350: `python carousel_kit.py spec.json out`
- `fonts/` — Playfair Display Italic і Montserrat.
- `приклад/spec.json` — еталонна карусель «5 фраз з дитинства, які забрали твій голос». Фото до неї (папка `фото/`) не збережені.
- `каруселі/` — сюди складаємо нові каруселі: `каруселі/<дата-тема>/spec.json`, `фото/`, `out/`.

Для Claude: на початку сесії прочитай `ІНСТРУКЦІЯ.md` і дотримуйся її.
